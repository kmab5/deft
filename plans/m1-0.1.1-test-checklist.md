# M1 patch 0.1.1 — device retest

This covers the second screenshot review. Earlier feedback and the author's marks remain in [the original checklist](m1-test-checklist.md) and [the first retest](m1-feedback-retest-checklist.md). The [visual reference](design/m1-feedback.html) shows the current rendered screens.

## Install and version

- [ ] Install `app/build/outputs/apk/release/deft-0.1.1.apk` over the existing release, without uninstalling. Books, folders, exclusions and preferences remain.
- [ ] Android shows version `0.1.1`. The same release certificate signs this and future updates.

## Library controls

- [ ] The toolbar feels compact and familiar: filter/current filter, current sort and direction, then the display icon. No separate sorting caption or permanent completed-scan rows.
- [ ] Filters use checkboxes and apply immediately. Clear filters restores all Books without changing which formats are scanned.
- [ ] Sort uses radio choices with a clear direction control. Last read explains that unread Books come last; M1 creates no reading history.
- [ ] Display offers adjacent grid/list choices and three sizes. Each layout remembers its size after relaunch.
- [ ] Each popup fits its content, closes with X, outside tap or Back, and scrolls when needed. Nothing is clipped at 150% system font size.
- [ ] Useful icons are recognizable; TalkBack names icon-only actions and announces selected controls.

## Scan results and notices

- [ ] Start a scan. Only running progress appears in the page. Switch to Settings and back while scanning; it remains accurate.
- [ ] Finish a scan. A bottom notice offers **scan details**, then disappears after about six seconds without interaction. Android accessibility timeout preferences may extend this.
- [ ] Hold or keyboard-focus a notice: it stays while interacting, then gets a fresh reading interval after release/focus leaves. Close dismisses it immediately with motion.
- [ ] Reopen the app after the notice expires. The old completion notice does not reappear. The Books overflow still offers **last scan**.
- [ ] Scan details opens its own popup. Inspect named added/updated/restored files, skipped/unchanged/duplicate files, and errors/fallbacks, with paths and reasons.
- [ ] Enable PDF in Library settings before scanning a known EPUB/PDF folder. Both appear when the Books filter allows them; disabled scan types appear as skipped with an explanation.
- [ ] Rescan unchanged files: they are listed as unchanged rather than falsely shown as new additions.
- [ ] Start a large scan, leave the app and return. It continues with its notification, and the final report retains names across any continuation.
- [ ] Cancel a running scan from its notification. Already imported Books remain. Details identify records saved before cancellation and do not claim the scan completed.
- [ ] A malformed/unreadable sample has a useful error or fallback reason. An unavailable folder is reported without erasing reading history or falsely marking an incomplete traversal missing.

## Settings and error feedback

- [ ] Settings still opens Library directly while it is the sole implemented section. A category chooser is planned when a second section exists.
- [ ] Pick an exclusion outside its parent: an error slides up from the bottom, leaving folder controls in place. It is not inserted into the page body.
- [ ] Trigger different errors in succession: notices stack and dismiss independently; further queued notices are not lost. Repeated identical errors do not flood the stack.
- [ ] Folder add/exclude/include/remove controls are visible and use meaningful icons. Removing a folder still asks for confirmation and preserves history.
- [ ] Storage shows databases, covers, scan reports and temporary cache. Original book files remain untouched.

## Motion and compatibility

- [ ] Popup entry/exit, notices, confirmation dialogs, layout changes, selection, reorder and folder/exclusion changes are smooth. Scanning many Books does not repeatedly animate the whole library.
- [ ] Disable Android animations and repeat popup/notice/layout actions: controls work immediately without getting stuck. Restore the preferred system setting afterward.
- [ ] Check paper and ink, large fonts, TalkBack and fast repeated navigation on the Samsung S25 FE.
- [ ] Check Android 8/9 on hardware if available; otherwise leave unverified.
