# M4 0.4.1 review fixes and validation

> **Historical record:** M1-M4 are complete. This document preserves the implementation/review state at its original handover; pending status and task checkboxes below are not current work. See the [documentation index](README.md) and [roadmap](2026-11-13-deft-roadmap.md) for current status and milestone numbering.

## Main branch adjustment

The author explicitly requested the M3 idle visual adjustment directly on main,
without building it. Commit `2eecda1` was pushed before M4 work resumed. It darkens
the black film to 55% and supplies a full-width pulsing black band behind a white
label. The band reaches about 87% combined black opacity. Reduced motion keeps
it steady. Merge `257b258` incorporates it into this M4 build; original device
comments are preserved.

## Feedback coverage

- Shared icon/border menu on Books, Categories and Authors, plus horizontal tab
  gestures and directional transitions. Scan notices separate status, concise
  counts and details; they occupy the content area above bottom navigation.
- Books selection bar fits large counts, and Books no longer exposes or applies
  category filtering. Category-scoped browsing belongs to the Categories tab.
- Category actions, filters, sorting and display are separated. Persistent sort,
  review/type/state filters and author count/time/rating/state filters compose
  with search. Individual preference updates do not overwrite one another.
- Category list/grid and member list/grid display covers. Detail rating/reset,
  identity/actions and suggestion review have distinct compact groups. Ordering
  and reorder are visible. The editor anchors save/cancel beneath grouped fields.
- Add-books picker has lazy cover/metadata rows, search/sort/filter and a fixed
  tick/count action. Merge-target chooser adds search and sorting.
- File-location sorting is available for Books, non-Series members, picker and
  author detail. A present file is preferred, then display path and stable ID.
  Author sorting consistently uses the first effective author's stored sort name.
- Series drag reorders the exact visible membership set. Unique number slots,
  including fractions, are retained; duplicate slots renumber 1..N as disclosed.
  Ignored memberships, aliases and explicit scan exclusions remain intact.

## Regression and audit evidence

The domain red batch failed on missing location/Series reorder contracts; the
subsequent grouped run passed database and organization tests. The controls red
batch recorded missing browse preference/helper contracts. Regression additions
cover composed queries, persisted and concurrent preferences, stale Books category
filters, decimal reorder/rescan/invalid permutations, canonical locations and
first effective author keys, selection with large counts, picker confirmation
while scrolled/filtered, and tab directions/boundaries.

The combined audit found one P2 inconsistency: new book browsing used displayed
author names while the established library uses the author's sort name. All
projections and browse helpers now share the authoritative key, with inversion
and coauthor tie regressions. The source review is recorded locally under
`.superpowers/review-041/`; final disposition and build evidence follow below.

The scoped audit recheck has no open findings. Additional regressions exercise
nested horizontal scrolling, vertical scrolling and page-swipe navigation, plus
equal case-insensitive file paths, ID tie-breaking, all-missing and no-file
location fallbacks. The layout assertions measure spacing after the complete
notice message, including wrapped counts, rather than treating that text as
empty space. Complexity findings were resolved by extracting browse predicates
and member/header components without suppressions.

Native render inspection covered category grid/list/detail, author detail and
landscape, editor/picker at 150% text, a six-digit selection count at 150%, and
stacked scan/error notices in both themes (paper at 150%). No action overlap or
clipping was observed in these captures.
