choices lacked selected semantics. The fix and its UI assertion passed the
scoped recheck, leaving no open source findings. The review is recorded in
`.superpowers/review-042/audit.md`.

and notice list); the test now uses the actual merge-list tag. The landscape
native test also needed Compose to finish the confirmation exit animation before
awaiting the persisted result. With that synchronization, all 21 organization
debug tests passed, including exact merge target persistence and rating
cancel/save/reset. No merge rules were changed.

Native render inspection led to equal-height paired actions, a books-heading
display toggle, and a second toolbar row at narrow widths so “date created” never
breaks inside a word. [The gallery](design/m4-042-review.html) covers the normal
phone layouts, 320/360dp at 150% text and landscape. The multi-window merge
confirmation diagnostic is excluded: Roborazzi warns that it composites multiple
windows, and the image includes the underlying picker over the dialog. The
displayed-button interaction and persisted outcome pass; physical stacking is
still a device check.
