## Regression evidence

The pre-fix batch demonstrated missing author links, Apply placement/keyboard
behavior, state selection, rating alignment and idle film/resume failures. The
haptic mapping and successful-pop regressions also failed before implementation.
The first haptic run attempted to fetch an uncached Android 9 test runtime; its
worker was stopped and the fallback-mapping test was changed to use the installed
runtime while temporarily setting the API level. This tests mapping, not Android
9 hardware behavior. One touch-test receiver typo was corrected before its
intended rating-layout failure was observed.

## Verification

The combined audit found a wake-gesture issue: a clickable-only film swallowed
swipes without resuming. The overlay now consumes the full touch gesture and
resumes on release; a swipe regression complements the tap and accounting tests.
The celebration, state sheet and accepted calendar date now send haptics through
their active dialog/picker views instead of an obscured activity view.

The final grouped `ktlintFormat check assembleRelease` passed (1m 36s), with
899 test executions: 430 debug, 430 release and 39 JVM tests; zero failures,
errors or skips. Ktlint, detekt, Android lint and network isolation passed.
The combined source audit has no unresolved blockers. Fresh Compose renders for
ratings, state choices, inline timers, About and the idle film were inspected,
including dark theme and 150% text. The visual reference and component golden
images are updated.
