# M3 0.3.3 — final reader follow-up

The author passed the 0.3.2 checklist and requested two remaining fixes, followed
by a direct commit/push on main before starting M4. Original comments remain in
the checklist.

- Idle mode now uses a 38% black film in every reader theme, with the existing
  faint pulsing label and consumed wake gesture.
- Paged and continuous readers send system-respecting LONG_PRESS feedback when
  an actual nonempty text selection first appears. Toolbar recreation and handle
  adjustment do not repeat it. Observation stops while paused or detached and
  retries transient selection-read failures without crashing.

Regression tests failed against the previous behavior, then passed. The initial
test harness needed Robolectric and the project's existing Roborazzi capture
path before those behavioral failures could be demonstrated. The scoped audit
found transient-read and background-polling issues; both were fixed and reviewed
again with no open findings.

`ktlintFormat :feature:reader:detekt :feature:reader:testDebugUnitTest check
assembleRelease` passed in 11m 41s. All 909 test executions passed: 435 debug,
435 release and 39 JVM, with no failures, errors or skips. Android lint, detekt,
ktlint and network isolation passed. The rendered white-page film was inspected.
The release verifier confirmed the persistent signing certificate, app identity,
version, no INTERNET permission and R8 mapping. Version is 0.3.3-1, code 30301.

No physical-device haptic-strength claim is made; USB remains unavailable.
The source-stamped release APK and mapping are archived locally under
`.superpowers/releases/0.3.3/`. GitHub CI completion is not awaited.
