- Rapid Back calls could pop an outgoing destination again and empty the root stack. Destination-scoped callbacks now check the current entry and lifecycle; transition-time events are consumed. Tests exercise repeated and stale callbacks against a real NavHost.
- The prior image fix did not resolve the author's blank viewer. Its original WebView cause remains unconfirmed; the earlier 0.2.3 interception diagnosis must not be treated as established. The viewer now decodes publication resources into a native image surface, removing the HTML/data-URL transport. Raster/SVG dimensions, bytes and reference graphs are bounded; malformed content has visible recovery. AndroidSVG 1.4 is Apache-2.0, bundled with its license and no external resolver. Native Compose rendering, pixel output, pinch/pan and dismissal have regression coverage.
- Readium 3.2 slow release depends on velocity. Deft captures the starting native page and commits its exact adjacent target after a half-page drag. This replaces pending snap-back rather than issuing relative JavaScript navigation from a fractional offset. A small adapter uses pinned Readium internal pager APIs; dependency upgrades must review it. Tests exercise the real Readium pager with platform scroll geometry supplied by Robolectric.
- External HTTP(S) links require confirmation of the parsed domain and use a browser-selected intent only after confirmation. Invalid and non-web links cannot launch. Deft retains no INTERNET permission.
- Search locations use publication positions and the nearest preceding TOC anchor, including sections sharing one XHTML file. Library gutters, overlapping handle hit targets, aligned search cards, compact notices and reader spacing follow the author's feedback.
